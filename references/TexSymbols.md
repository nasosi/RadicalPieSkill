# TeX Symbols

Generated by `Scripts/BuildTexSymbols.py` from the documentation's TeX command tables. Edit the
script, never this file.

Radical Pie turns a TeX command typed in the editor into the character in the Unicode column. Read the
table the other way to go from the LaTeX a document already carries to the character an `Sb` symbol
holds. The commands in the first table insert a structure instead of a character; its Structure column
names the identifier to write, and `references/StructureCatalogue.md` says what goes inside it.
